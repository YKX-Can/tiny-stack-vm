# tiny-stack-vm

A tiny stack virtual machine for make.fun's tiny-stack-vm-01 ISA: one Node 22
program (`main.ts`) that runs every drawn bytecode program and answers with
exactly the bytes it writes and the exit code it ends with — wrapping 32-bit
arithmetic, unsigned div/mod/compare, all ten trap codes, and the step and
output limits included.
